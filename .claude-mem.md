## Key Decisions

- **`localizacao` como property**: coluna não existe no banco; `@property` evita crash ORM.
- **Models espelham schema real**: `managed=False` + fields exatos — sem Django abstractions.
- **User model**: `db_column='senha'` para password; `admin` como `IntegerField(0/1)`; `criado_em` como `DateTimeField` mas coluna é `text` — cuidado com queries SQL diretas.
- **BCrypt para senhas legadas**: Node.js usava bcrypt; Django com `BCryptPasswordHasher` + prefixo `bcrypt$$` no hash.
- **`core` em INSTALLED_APPS**: necessário para management commands discovery.
